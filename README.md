# AUTONOM

SaaS de agentes de IA para geração automática de sites e atendimento via WhatsApp.

## Arquitetura (tudo gratuito)

- **Frontend + Backend:** Next.js
- **Hospedagem:** Vercel (plano Hobby)
- **Banco de dados + Login:** Supabase (plano Free)
- **Versionamento:** GitHub
